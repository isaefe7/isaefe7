# Web Development Coursework

HTML, CSS and JavaScript projects and exercises from the *Web-Based Programming* course (Yıldız Technical University, Computer Education and Instructional Technology). They show the progression from first static pages to multi-page sites with JavaScript interactions.

Everything here is plain HTML/CSS/JS: no build step, just open the files in a browser.

**Live demo:** <https://isaefe7.github.io/isaefe7/projects/web-development-coursework/> (served with GitHub Pages)

## Projects

Larger, multi-page work in [`projects/`](projects/):

| Folder | What it is |
|---|---|
| [`final-projesi`](projects/final-projesi/) | Multi-page landing site for an English-learning service: home, about, services, pricing, booking and contact pages with a shared stylesheet and a small script. |
| [`midterm-project`](projects/midterm-project/) | Two-page personal site (home and projects) with two stylesheets and images. |
| [`events`](projects/events/) | Events site with About, Education and Future pages and JavaScript for the interactive parts. |
| [`odev-06`](projects/odev-06/) | Three-page "professional starter" site (home, content, portfolio) with a larger custom stylesheet. |
| [`finale-yonelik`](projects/finale-yonelik/) | Single-page sports site with JavaScript. |

## Exercises

Smaller weekly assignments in [`exercises/`](exercises/): first HTML pages (`html-01`), CSS layout practice (`html-css-*`, `odev-01` … `odev-05`), and JavaScript practice such as a letter-grade checker using conditionals and `switch` (`odev-07`), DOM manipulation (`java-01`, `java-02`, `odev-08`) and a weekly challenge (`week13-challenge`).

## Skills practised

HTML structure and forms · CSS layout with Flexbox and Grid · media queries · DOM manipulation and event handling in vanilla JavaScript
