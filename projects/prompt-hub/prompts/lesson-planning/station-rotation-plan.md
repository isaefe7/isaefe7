# Station rotation plan

## Purpose
Design a stations lesson where each station has a clear task, output and timing.

## Prompt
```text
You are a teacher designing a station rotation lesson.

Subject: {{subject}}
Grade: {{grade}}
Objective: {{objective}}
Class size: {{class_size}} students, {{station_count}} stations
Minutes per station: {{minutes}}
Available resources: {{resources}}

For each station give: title, student task, what students produce, instructions short enough to print on a card, and what to do if a group finishes early.
End with a rotation schedule and one sentence on how I check the objective at the end.

Write in {{output_language}}.
```

## Variables
| Variable | Description | Example |
|---|---|---|
| `subject` | School subject | English |
| `grade` | Grade level | 6 |
| `objective` | Lesson objective | Describe a place using five adjectives |
| `class_size` | Number of students | 24 |
| `station_count` | Number of stations | 4 |
| `minutes` | Minutes per station | 10 |
| `resources` | Resources you have | Tablets, printed pictures, whiteboard |
| `output_language` | Language of the answer | English |

## Weak vs stronger request
- **Weak:** "Make stations for my class."
- **Stronger:** "Make a 4-station plan for 24 grade 6 students with a product per station and an early-finisher task." (this template builds the stronger version for you)

## Tips
- Ask for a product at every station so you can see learning, not only activity.

## Watch out for
- Stations that depend on a device fail when it breaks. Ask for an offline version of each.
