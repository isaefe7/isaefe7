# Warm-up activities

## Purpose
Get five-minute openers that activate prior knowledge instead of filling time.

## Prompt
```text
You are an experienced teacher who opens lessons with purposeful warm-ups.

Subject: {{subject}}
Grade: {{grade}}
Today's topic: {{topic}}
Prior knowledge students should have: {{prior_knowledge}}

Give {{count}} different warm-up activities of at most {{minutes}} minutes each. For each one state:
- what students do,
- which prior knowledge it activates,
- what a teacher can observe to see whether students are ready,
- materials needed (prefer none).

Write in {{output_language}}.
```

## Variables
| Variable | Description | Example |
|---|---|---|
| `subject` | School subject | History |
| `grade` | Grade level | 9 |
| `topic` | Today's topic | Causes of the First World War |
| `prior_knowledge` | What students already know | Map of Europe, empires in 1900 |
| `count` | Number of activities | 3 |
| `minutes` | Maximum minutes | 5 |
| `output_language` | Language of the answer | English |

## Weak vs stronger request
- **Weak:** "Give me warm-ups for history."
- **Stronger:** "Give 3 five-minute warm-ups on the causes of WWI that activate students' knowledge of the map of Europe, with what to observe." (this template builds the stronger version for you)

## Tips
- Rotate formats (writing, pairs, movement) so openers do not become routine.

## Watch out for
- A warm-up that is fun but unrelated to the topic wastes time. Check the link to today's topic.
