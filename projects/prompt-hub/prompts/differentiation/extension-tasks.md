# Extension tasks for advanced learners

## Purpose
Create tasks that deepen understanding for students who finish early, instead of giving them more of the same exercises.

## Prompt
```text
You are a teacher who specialises in challenging able learners.

Subject: {{subject}}
Grade: {{grade}}
Topic taught today: {{topic}}
Core task everyone completes: {{core_task}}

Create {{count}} extension tasks. Each one must:
- Go deeper (ask "why" or "what if"), not just add more items or higher numbers.
- Be doable independently in about {{minutes}} minutes with: {{resources}}.
- Use a different thinking skill (for example: create, compare, find the error, generalise,
  connect to real life).
- Include a one-sentence success criterion and, where relevant, a short hint card
  the student may ask for.

Add a teacher note with what a strong answer looks like for each task.
Write in {{output_language}}.
```

## Variables
| Variable | Description | Example |
|---|---|---|
| `subject` | School subject | Mathematics |
| `grade` | Grade level | 5 |
| `topic` | Topic of the lesson | Equivalent fractions |
| `core_task` | What the whole class does | Fold paper strips to find equivalent fractions |
| `count` | Number of tasks | 3 |
| `minutes` | Time per task | 10 |
| `resources` | Materials students can use | Paper, pencil |
| `output_language` | Language of the answer | English |

## Tips
- Print the tasks as separate cards so students can choose, which keeps motivation high.
- Ask for a "find the error" task: a worked example with one hidden mistake works well for most topics.

## Watch out for
- Check the "strong answer" notes yourself, particularly for mathematics.
