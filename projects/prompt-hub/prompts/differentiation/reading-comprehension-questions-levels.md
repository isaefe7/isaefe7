# Reading questions by level

## Purpose
Write comprehension questions that range from finding facts to evaluating ideas.

## Prompt
```text
You are a literacy teacher.

Text (paste below):
{{text}}

Grade: {{grade}}
Write {{count}} questions in three groups: (1) find it in the text, (2) infer from the text, (3) give your opinion and defend it with the text. Mark the line of the text each question uses. Do not ask anything the text cannot answer.

Write in {{output_language}}.
```

## Variables
| Variable | Description | Example |
|---|---|---|
| `text` | The text to use | Paste your text here |
| `grade` | Grade level | 7 |
| `count` | Questions per group | 2 |
| `output_language` | Language of the answer | English |

## Weak vs stronger request
- **Weak:** "Make questions from this text."
- **Stronger:** "Write two questions per level (find, infer, evaluate) and mark which line each one uses." (this template builds the stronger version for you)

## Tips
- Use the three groups to let every student start from the first and move up.

## Watch out for
- Check that every inference question has exactly one defensible answer from the text.
