# Message to parents

## Purpose
Write a clear, respectful note to parents about a class matter.

## Prompt
```text
You are a teacher writing to parents.

Purpose: {{purpose}}
Key facts (only these): {{facts}}
Tone: {{tone}}
Action needed from parents (or "none"): {{action}}

Write a message under {{words}} words with a subject line. Use plain language, no jargon, no blame, and no details about any individual child. Put the date or action in the first two sentences.

Write in {{output_language}}.
```

## Variables
| Variable | Description | Example |
|---|---|---|
| `purpose` | Purpose of message | Reminder about the museum trip |
| `facts` | Facts to include | Friday 10 May, bus leaves 8:30, bring lunch |
| `tone` | Tone | Friendly and clear |
| `action` | Action needed | Return the permission slip by Wednesday |
| `words` | Maximum words | 120 |
| `output_language` | Language of the answer | English |

## Weak vs stronger request
- **Weak:** "Write to parents."
- **Stronger:** "Write a 120-word note with subject line, date and action in the first two sentences, and no individual child's details." (this template builds the stronger version for you)

## Tips
- Read it as a parent: could they act on it without asking you a question?

## Watch out for
- Do not paste a child's name or personal details. Add them yourself after.
