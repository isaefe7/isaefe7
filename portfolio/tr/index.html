Hakkımda

2021'den beri Bilgisayar ve Öğretim Teknolojileri Öğretmenliği okuyorum. Yazılım geliştirme, veri tabanları, ağlar ve siber güvenlikte temelim var; öğrenme materyali tasarlama konusunda uygulamalı deneyimim var.

Hedefim, eğitimcilerin üretken yapay zekâyı iyi kullanmasına yardım eden bir İstem Mühendisi olmak: istemlerin paylaşılıp geliştirildiği bir Prompt Hub kurarak ve istem mühendisliği üzerine bir kitap yazarak. Bu site ilk adımları topluyor.

Şu anda yenilikçi eğitim teknolojileri üzerine bir TÜBİTAK proje önerisi hazırlıyorum (başvuru bekliyor).

Projeler

Lesson Plan Assistant

Bir Claude modelinden ders planı isteyen ve yanıtı göstermeden önce kodla doğrulayan (tam süre, kazanım sayısı) Python komut satırı aracı. Onarım adımı ve 31 çevrimdışı test içerir.

  • Python
  • LLM
  • Test

Prompt Hub

Öğretmenler ve öğretim tasarımcıları için küçük bir istem şablonu kütüphanesi; her şablonun düzenini denetleyen bir kontrol aracıyla. Daha büyük bir topluluk platformunun tohumu.

  • İstem mühendisliği
  • Eğitim
  • Python

Ders Saati

Ders programını XLS, CSV, JSON veya XML'den içe aktaran ve her dersten önce haftalık bildirim planlayan Flutter uygulaması. Supabase ile e-posta girişi.

  • Flutter
  • Dart
  • Supabase

Election Database

Bir seçimin (seçmen, aday, parti, sandık, oy) ilişkisel tasarımı: Chen diyagramından T-SQL şemasına, örnek veri ve sorgulara.

  • SQL Server
  • T-SQL
  • ER modelleme

Web Development Coursework

Tarayıcıda çalışan çok sayfalı HTML, CSS ve JavaScript siteleri ile haftalık alıştırmalar.

  • HTML
  • CSS
  • JavaScript
